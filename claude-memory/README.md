# Catatan sesi Claude Code

Ini salinan file memori Claude Code untuk project ini (konteks lintas-sesi:
arah desain, arsitektur Invest/Laporan Harian, fitur BOT NEWS, dsb).

## Cara pakai di PC baru
Salin semua file `.md` di folder ini ke:

`C:\Users\<NAMA>\.claude\projects\f--Panel-AUTO-RESULT\memory\`

(buat foldernya kalau belum ada). Setelah itu Claude Code akan otomatis
membaca catatan ini saat sesi berikutnya di project ini.

File `settings.json` Claude Code TIDAK disertakan — isinya spesifik per-PC
dan pernah memuat nilai rahasia; biarkan Claude Code membuatnya sendiri.
